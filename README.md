# جيران (Jeeran) - تراث يتناقله الأجيال 🧶✨

مرحباً بك في المستودع الرسمي لمشروع **جيران (Jeeran)**.
"جيران" هي منصة تجارة إلكترونية متكاملة، مستوحاة من فكرة تبادل الملابس المستعملة والأزياء المحتشمة بين الأجيال والجيران، لتعزيز الاستدامة والحفاظ على التراث الأصيل والمشاركة المجتمعية.

## 🌟 الفكرة والرؤية (The Concept)

اسم **"جيران"** يرمز إلى الألفة، الكرم، والمشاركة. المنصة متخصصة في عرض وبيع الملابس المستعملة ذات الجودة العالية (Pre-loved) والأزياء الإسلامية المحتشمة (عبايات، حجابات، أثواب، ملابس أطفال). 
تم تصميم الموقع بهوية أردنية/عربية تراثية أصيلة، مع استخدام اللهجة الأردنية (البيضاء) في نصوص واجهة المستخدم (مثل: "وصل حديثاً يا ربيع")، ليعطي طابعاً حميمياً يشبه التسوق من خزانة الجيران بكل ثقة وأمان.

## 🎨 الهوية البصرية (Visual Identity)

- **الألوان:** الأحمر الداكن المستوحى من السجاد التراثي (#A2231D)، والذهبي العتيق (#D4AF37)، مع خلفيات بلون الكريم الهادئ (#F5F5DC).
- **الخطوط:** خطوط عربية أصيلة مع تصميمات مستوحاة من الزخارف الإسلامية البسيطة.
- **التجربة:** تجربة مستخدم سلسة مشابهة لأكبر منصات التجارة الإلكترونية، لكن بهوية محلية، محتشمة، ومستدامة.

## ✨ أبرز مميزات المنصة (Key Features)

- 🛍️ **تجربة تسوق متكاملة:** واجهة مستخدم سريعة الاستجابة (Mobile-First) تدعم اللغة العربية بالكامل (RTL).
- 👗 **أزياء محتشمة ومستدامة:** أقسام مخصصة للنساء، الرجال، والأطفال، مع التركيز على الملابس المستعملة التي تنتقل من جيل لجيل.
- 🚚 **خيارات الدفع والشحن:** دعم كامل للدفع عند الاستلام (COD) مع نظام تأكيد الطلبات عبر الهاتف ليتناسب مع السوق الأردني.
- ⚙️ **لوحة تحكم (Admin Dashboard):** لوحة تحكم شاملة لإدارة المنتجات، الطلبات، المخزون، والعملاء بسهولة وفعالية.
- ⚡ **أداء عالي (Real-time):** تحديثات حية للمخزون وحالة الطلبات باستخدام قاعدة بيانات (Supabase).

## 💻 التطوير والتقنيات (Tech Stack)

تم بناء هذا المشروع بالاعتماد على منصة [Lovable](https://lovable.dev) وأحدث تقنيات تطوير الويب لضمان أفضل أداء:
- **Frontend:** React, TailwindCSS, Framer Motion
- **Backend:** Supabase (Auth, Database, Storage)

### التشغيل المحلي (Local Development)

إذا كنت ترغب في تشغيل وتطوير المشروع على جهازك:

```sh
# استنساخ المستودع
git clone https://github.com/ahmad00haddad/jeeran.git
cd jeeran

# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```
